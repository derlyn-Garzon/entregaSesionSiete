# assets

Aquí va la imagen del logo usada por la presentación.

- Nombre esperado: `logo.png`
- Formato: PNG con transparencia, recorte cuadrado, mínimo 256×256 px

El HTML la referencia en dos sitios:

```
línea   9   <link rel="icon" type="image/png" href="assets/logo.png">
línea 203   <img src="assets/logo.png" ...>
```

Si usas otro nombre o formato (por ejemplo `logo.svg`), actualiza ambas rutas.
